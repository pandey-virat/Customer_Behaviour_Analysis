# 📊 Customer Behaviour Analysis Dashboard

## 📌 Overview
This project analyzes customer behaviour using **Power BI** and **SQL Workbench**. It explores demographics, purchasing patterns, product categories, and subscription trends to deliver actionable business insights. The dashboard is interactive, cleanly designed, and built with professional best practices.

---

## 🎯 Objectives
- Understand customer segmentation by age, gender, and subscription status  
- Evaluate product categories by revenue, sales, and review ratings  
- Identify top-performing products and shipping preferences  
- Provide dynamic filtering for deeper business exploration  

---

## 🛠️ Tools & Technologies
- **Power BI Desktop** → Dashboard design, KPIs, slicers, visuals  
- **DAX Measures** → Custom calculations for revenue, averages, segmentation  
- **SQL Workbench** → Data extraction, cleaning, and transformation queries  
- **Google Colab** → Data preprocessing and exploratory analysis  

---

## 📊 Dashboard Features
- **KPIs**: Number of Customers, Average Purchase Amount, Average Review Rating  
- **Filters (Slicers)**: Subscription Status, Gender, Category, Shipping Type  
- **Visuals**:
  - Customer split by subscription status  
  - Revenue & Sales by Age Group and Category  
  - Top Products by Review Rating  
  - Purchase behaviour by Shipping Type  

---

## 🚀 How to Use
1. Clone the repository  
2. Open `colab_notebook.ipynb` for preprocessing steps  
3. Run SQL queries from `sql_scripts` to prepare data  
4. Open `powerbi_dashboard.pbix` in Power BI Desktop to explore the dashboard  

---

## 📌 Insights Delivered
- Clothing category drives the highest revenue and sales  
- Young customers contribute most to revenue and purchases  
- Majority of customers are non-subscribers (73%)  
- Average purchase amount is consistent across genders (~$60)  
- Shipping preferences vary, with Free and Express shipping being popular
